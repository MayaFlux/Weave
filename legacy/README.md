# Legacy implementations

This folder preserves the former Python, Swift, and .NET applications, their tests, platform packaging helpers, and development guides. Keep them as references for feature parity and packaging research while the Rust application is completed.

Active CI does not build or test this archive. To recover the exact old repository layout or scripts, fetch a tag from before the Rust migration. The active shared implementation is at the repository root (`src/`, `ui/`, and `templates/`).
