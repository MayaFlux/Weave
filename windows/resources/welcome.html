Welcome to MayaFlux

This installer will set up everything you need to start developing with MayaFlux, a next-generation digital multimedia processing framework.

📦
MayaFlux Framework — Latest stable release with core libraries and JIT compiler
🔧
Build Tools — CMake, compiler toolchain, and all required dependencies
🎨
Graphics & Audio — Vulkan SDK, FFmpeg, RtAudio, and related libraries
🚀
Project Creator — GUI tool to generate starter projects instantly

📋 Requirements

  • Windows 10 or later (64-bit)
  • ~2GB free disk space for framework and dependencies
  • Internet connection (for downloading components)
  • Administrator privileges (for installation)

Installation time: 5-15 minutes depending on internet speed.
