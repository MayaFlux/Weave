Quick Start Guide

Getting Started in 3 Steps

1
Restart your terminal to load environment variables
Command Prompt or PowerShell
2
Create your first project
weave new MyProject
3
Build and run
cd MyProject && mkdir build && cd build
cmake .. && cmake --build . --config Release
.\Release\MyProject.exe

Troubleshooting

Environment variables not working?
Restart your terminal completely. Close and reopen Command Prompt or PowerShell.

Missing dependencies?
Run the setup script manually:

powershell -ExecutionPolicy Bypass .\windows\scripts\setup_windows.ps1

Build errors?
Ensure you have Visual Studio Build Tools or Visual Studio 2019+ installed with C++ development tools.

Installation log: %LOCALAPPDATA%\weave_install.log
