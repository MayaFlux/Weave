Welcome to MayaFlux

This installer will set up MayaFlux, a next-generation digital multimedia processing framework.

What will be installed:

  • MayaFlux framework to ~/MayaFlux/
  • Required dependencies (Homebrew packages)
  • Vulkan SDK for graphics support
  • Weave project creator tool

Requirements:

  • macOS Sonoma (14.0) or later
  • ~2GB disk space for dependencies
  • Internet connection (for downloads)
