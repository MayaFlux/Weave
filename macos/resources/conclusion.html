Weave Installation Started! 🚀

Next Step: Complete Setup in Terminal

A Terminal window will open automatically to complete the MayaFlux installation. This will:

  • Install MayaFlux framework
  • Set up required dependencies (Homebrew, Vulkan SDK, etc.)
  • Configure your development environment
  • Install the Weave CLI tool
1
Wait for Terminal

The Terminal window will guide you through the remaining installation steps. This may take several minutes as dependencies are downloaded and installed.

2
Follow Terminal Instructions

Follow the prompts in the Terminal window. The installer will:

  • Download and install MayaFlux
  • Set up Homebrew dependencies
  • Install Vulkan SDK
  • Configure your shell environment
3
Restart Terminal

After installation completes, restart your Terminal or run:

source $ZDOTDIR/.zshenv

🎉 Create Your First Project

Once installation is complete, you can create projects using either method:

GUI Method:

open /Applications/Weave.app

CLI Method:

weave new MyFirstProject ~/Projects/

⚠️ Important Notes

  • Don't close the Terminal window that opens automatically
  • The installation may take 10-15 minutes depending on your internet connection
  • You may be prompted for your password during installation
  • After installation, restart your Terminal for environment changes to take effect
