🎉 Create Your First Project

Weave will launch automatically. Use it to create your first MayaFlux project with a custom name and location.

You can also find Weave later in /Applications/Weave.app

Alternative: Using the CLI

  1. Open a new Terminal window
  2. Create a project: 
    weave new MyFirstProject ~/Projects/
  3. Build and run: 
    cd ~/Projects/MyFirstProject
                    mkdir build && cd build
                    cmake .. && make
                    ./MyFirstProject
